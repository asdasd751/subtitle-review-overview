# 字帧｜SRT 字幕校样回传工具

> 技术验证原型 · 公开作品介绍
>
> 本仓库仅展示功能说明和合成文字流程，不提供工具程序、源代码或下载包。尚未正式销售；不代表平台认证已通过。

## 解决什么问题

已有 SRT 字幕需要交给客户或同事核对文字时，让审阅人逐条改字、写备注、标记疑问，再由制作者对照原文决定是否采用。编号与时间轴保持只读，不用于调整字幕时间。

## 三步流程

1. **导入 SRT，发出校样。** 制作者导入 UTF-8 SRT，保存工程备份，生成独立 HTML 校样包，通过自行选择的渠道交给授权审阅人。
2. **独立校样，改字和备注。** 审阅人逐条修改文字、填写备注或勾选疑问，下载回传 JSON 并发回。
3. **回传确认，导出结果。** 制作者打开对应工程或恢复备份，导入 JSON，逐条选择接受修改或保留原文，再下载修订 SRT 与修改清单。

### 合成文字演示

以下内容完全虚构，仅说明交互流程，不是真实用户字幕：

- 原字幕：`欢迎来到今天的字慕课堂。`
- 审阅人建议：`欢迎来到今天的字幕课堂。`
- 备注：`“字慕”疑似错字，请确认。`
- 制作者导入回传后选择“接受修改”，导出的字幕采用新文字，原编号和时间码保持不变；选择“保留原文”则不采用这条改字。

此处是文字示例，不是在线演示或可下载校样包。

## 功能与范围

- 支持 UTF-8 SRT（可带 BOM），LF 或 CRLF 换行，最多 1000 条、原文件最多 2 MiB。
- 原文与回传逐条并排对照；不是字符级着色差异比较。
- 校验工程标识、文件一致性及回传版本，不匹配时拒绝导入。
- 支持工程备份、独立校样包、回传 JSON、修订 SRT 与修改清单的文件流程。
- 不提供语音识别、自动翻译、AI 改写、视频播放或时间轴编辑。
- 不支持多人实时协作、自动合并多份回传、云同步或账号管理。

## 验证现状与重要限制

截至 2026 年 11 月 1 日，原型完成 **14 项自动化测试，0 失败、0 跳过**；在**云 Chromium 的 localhost 预览**中完成 1000 条字幕的校样、真实下载、回传确认与导出闭环验证。末条中文、emoji、换行与备注修改后，导出的 SRT 与预期逐字节一致，其余 999 条保留。

**Windows/macOS 桌面的真正本地 `file://` 打开尚未验收。** 云预览通过不能替代本机兼容验收；当前不应视为成熟正式版或跨平台兼容保证。上述测试也不等于独立安全审计。

请保留原文件并下载工程与回传备份。浏览器缓存不是唯一可靠副本，不保证关闭或刷新后不丢数据。校样包、工程备份及回传可能含完整字幕，文件未加密；只应交给获授权的人员。文件一致性校验不等于身份认证或保密保证。
